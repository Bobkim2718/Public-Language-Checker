# 쉬운 우리말 공식 사전 스냅샷

- 레코드 수: 3,581
- 형식: keyword / alt
- 용도: 문서 전체를 외부로 보내지 않고 PC에서 빠르게 등재 표현을 찾기 위한 로컬 스냅샷
- 상세 예문: 앱의 공식 API 상세 조회 기능으로 필요할 때 조회

앱에서는 이 데이터의 출처 유형을 `OFFICIAL`로 표시합니다. 이후 공식 사전 변경분은 업데이트 번들의 `official_terms`로 추가·수정할 수 있습니다.
